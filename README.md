# Portfolio · Jorge Meza

Dashboard de CV y proyectos (Next.js + Tailwind + Framer Motion, export estático).

- `npm run dev` → http://localhost:3000
- `npm run build` → genera `out/` (sitio estático)
- Todo el contenido vive en `data/` (`projects.ts`, `experiencia.ts`, `formacion.ts`).

## Cambiar la foto de perfil

1. En GitHub, entrá a la carpeta `public/`.
2. **Add file → Upload files** y subí la foto con el nombre exacto `jorge.png` (reemplaza la anterior).
3. **Commit changes**. Vercel redespliega solo en 1–2 minutos.

Si `public/jorge.png` no existe, el sitio muestra una silueta de reemplazo.
